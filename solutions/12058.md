# Id 12058 — function findSequence

```c
int findSequence(int SIZE, int *arr) {
    int i = 1;
    while (i < SIZE && arr[i - 1] > arr[i])
        i++;
    if (i == 1)
        return 0;
    while (i < SIZE - 1 && arr[i] < arr[i + 1])
        i++;
    return i == SIZE - 1 ? 1 : 0;
}
```
