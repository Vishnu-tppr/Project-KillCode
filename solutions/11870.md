# Id 11870 — function getCommonFactorsCount

```c
int getCommonFactorsCount(int a, int b) {
    if (a < 0) a = -a;
    if (b < 0) b = -b;
    int m = a < b ? a : b, c = 0;
    for (int i = 1; i <= m; i++)
        if (a % i == 0 && b % i == 0) c++;
    return c;
}
```
