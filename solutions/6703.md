# Id 6703 — Count of Positive, Negative and Zeroes

```c
#include <stdio.h>

int main() {
    int n, x, p = 0, ne = 0, z = 0;
    scanf("%d", &n);
    for (int i = 0; i < n; i++) {
        scanf("%d", &x);
        if (x > 0) p++;
        else if (x < 0) ne++;
        else z++;
    }
    printf("%d %d %d\n", p, ne, z);
    return 0;
}
```

Verified: `6 /9 0 -1 -5 -10 0 → 1 3 2`, `7 /4 0 -10 -13 8 9 0 → 3 2 2`
