# Id 7084 — Number Increment Pattern

```c
#include <stdio.h>
int main(){
    int N;
    scanf("%d",&N);
    int step=2, val=N;
    for(int r=1;r<=N;r++){
        int last=val+(N-1)*step;
        for(int c=0;c<N;c++){
            if(c) printf(" ");
            printf("%d",val+c*step);
        }
        printf("\n");
        step=(step==2)?3:2;
        val=last+step;
    }
    return 0;
}
```

Verified: 4 → rows (4..10),(13..22),(24..30),(33..42) ; 5 → rows (5..13),(16..28),(30..38),(41..53),(55..63)
