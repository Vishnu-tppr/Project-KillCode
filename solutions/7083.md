# Id 7083 — Alphabet Pattern Printing

```c
#include <stdio.h>
int main(){
    int N;
    scanf("%d",&N);
    int pos=1;
    for(int r=1;r<=N;r++){
        int first=1;
        for(int c=1;c<=r;c++,pos++){
            if(!first) printf(" ");
            char ch=(pos-1)%26+'a';
            if(pos%2==0) ch-=32;
            printf("%c",ch);
            first=0;
        }
        printf("\n");
    }
    return 0;
}
```

Verified: 4 → a/B c/D e F/g H i J ; 8 → 8 rows with proper case cycling
