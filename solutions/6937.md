# Id 6937 — Odd Position and Even Position Elements

```c
#include <stdio.h>
int main(){
    int n; int a[50]; int i;
    scanf("%d",&n);
    for(i=0;i<n;i++)scanf("%d",&a[i]);
    for(i=0;i<n;i++){
        if(i>0)printf(" ");
        if((i+1)%2==1)printf("%d",a[i]*2);
        else printf("%d",a[i]*a[i]);
    }
    printf("\n");
    return 0;
}
```

Verified: `5\n3 4 5 6 7 → 6 16 10 36 14`; `3\n10 24 36 → 20 576 72`
