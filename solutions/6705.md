# Id 6705 — Cube of the Value from N to 1

```c
#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);
    int f = 0;
    for (int i = n; i >= 1; i--) {
        if (f) printf(" ");
        f = 1;
        printf("%d", i * i * i);
    }
    printf("\n");
    return 0;
}
```

Verified: `5 → 125 64 27 8 1`, `3 → 27 8 1`
