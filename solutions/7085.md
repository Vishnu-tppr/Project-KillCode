# Id 7085 — Pattern Printing - Alternate 1 to N

```c
#include <stdio.h>
int main(){
    int N;
    scanf("%d",&N);
    for(int i=1;i<=N;i++){
        int v=(i%2==1)?(i+1)/2:N-i/2+1;
        for(int c=0;c<N;c++) printf("%d",v);
        printf("\n");
    }
    return 0;
}
```

Verified: 5 → 1,5,2,4,3 each x5 ; 6 → 1,6,2,5,3,4 each x6
