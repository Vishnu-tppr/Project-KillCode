# Id 6706 — Integers from N to 1 - Not Divisible by X

```c
#include <stdio.h>

int main() {
    int n, x;
    scanf("%d%d", &n, &x);
    int f = 0;
    for (int i = n; i >= 1; i--) {
        if (i % x != 0) {
            if (f) printf(" ");
            f = 1;
            printf("%d", i);
        }
    }
    if (!f) printf("-1");
    printf("\n");
    return 0;
}
```

Verified: `10 4 → 10 9 7 6 5 3 2 1`, `4 1 → -1`
