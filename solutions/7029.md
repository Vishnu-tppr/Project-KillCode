# Id 7029 — Profit or Loss - Bike

```c
#include <stdio.h>
int main(){
    long long X,Y,Z;
    scanf("%lld %lld %lld",&X,&Y,&Z);
    long long d=Z-(X+Y);
    if(d>0) printf("%lld Profit",d);
    else if(d<0) printf("%lld Loss",-d);
    else printf("No Profit No Loss");
    return 0;
}
```

Verified: 12000 5000 21000 → 4000 Profit ; 50000 12000 62000 → No Profit No Loss
