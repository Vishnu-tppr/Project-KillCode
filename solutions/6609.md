# Id 6609 — Rainbow Colours

```c
#include <stdio.h>

int main() {
    char c;
    scanf("%c", &c);
    if (c == 'V') printf("Violet\n");
    else if (c == 'I') printf("Indigo\n");
    else if (c == 'B') printf("Blue\n");
    else if (c == 'G') printf("Green\n");
    else if (c == 'Y') printf("Yellow\n");
    else if (c == 'O') printf("Orange\n");
    else if (c == 'R') printf("Red\n");
    else printf("Invalid\n");
    return 0;
}
```

Verified: `V → Violet`, `L → Invalid`, `Y → Yellow`
