# Id 14275 — Unique Characters Number

```c
int numberUniqueCharacter(char *str) {
    int seen[26] = {0};
    int count = 0;
    int i;
    for (i = 0; str[i]; i++) {
        int idx = str[i] - 'a';
        if (idx >= 0 && idx < 26 && seen[idx] == 0) {
            seen[idx] = 1;
            count++;
        }
    }
    return count;
}
```
