# Id 15153 — function getMinimumDeletions

```c
int getMinimumDeletions(int SIZE, int *arr) {
    int best = 1, len = 1, i;
    for (i = 1; i < SIZE; i++) {
        if (arr[i] >= arr[i - 1]) len++;
        else len = 1;
        if (len > best) best = len;
    }
    return SIZE - best;
}
```
