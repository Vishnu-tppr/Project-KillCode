# Id 7116 — Weight of the String

```c
#include <stdio.h>

int main() {
    char s[101];
    scanf("%s", s);
    int sum = 0;
    for (int i = 0; s[i]; i++) {
        char c = s[i];
        if (c >= 'a' && c <= 'z') sum += c - 'a' + 1;
        else if (c >= 'A' && c <= 'Z') sum += c - 'A' + 1;
    }
    printf("%d\n", sum);
    return 0;
}

```
