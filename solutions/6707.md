# Id 6707 — Maximum Sum

```c
#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);
    int s1 = 0, s2 = 0;
    for (int i = 0; i < n; i++) {
        int v;
        scanf("%d", &v);
        int t = (v / 10) % 10;
        if (t % 2) s1 += t;
        else s2 += t;
    }
    printf("%d\n", s1 > s2 ? s1 : s2);
    return 0;
}
```

Verified: `5 /10 20 30 40 50 → 9`
