# Id 6883 — String Equality Ignoring Case

```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>
int main(){
    char a[1001],b[1001];
    scanf("%s %s",a,b);
    int len=strlen(a);
    int eq=1;
    if(strlen(b)!=len){eq=0;}
    else{
        for(int i=0;i<len;i++){
            if(tolower(a[i])!=tolower(b[i])){eq=0;break;}
        }
    }
    if(eq)printf("YES\n");
    else printf("NO\n");
    return 0;
}
```

Verified: `hello HeLlO → YES`; `tellme Telime → NO`
