# Id 6633 — Print Digit - Unit and Tenth

```c
#include <stdio.h>

int main() {
    int n, d;
    scanf("%d%d", &n, &d);
    if (d == 1) printf("%d\n", n % 10);
    else if (d == 2) printf("%d\n", (n / 10) % 10);
    else printf("%d\n", (n % 10) * ((n / 10) % 10));
    return 0;
}
```

Verified: `14 2 → 1`, `231 5 → 3`
