# Id 6930 — Same Position Elements in Two Arrays

```c
#include <stdio.h>
int main(){
    int n; int a[50],b[50]; int i;
    scanf("%d",&n);
    for(i=0;i<n;i++)scanf("%d",&a[i]);
    for(i=0;i<n;i++)scanf("%d",&b[i]);
    for(i=0;i<n;i++)printf("%d %d\n",a[i],b[i]);
    return 0;
}
```

Verified: `5\n6 7 8 5 3\n8 7 5 3 1 → 6 8/7 7/8 5/5 3/3 1`; `3\n234 364 756\n37 927 2234 → 234 37/364 927/756 2234`
