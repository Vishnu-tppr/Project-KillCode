# Id 5415 — C - Function - Odd Factors Count

```c
#include <stdio.h>
int getOddFactorCount(int N) {
    int c = 0;
    for (int i = 1; i <= N; i++)
        if (N % i == 0 && i % 2 == 1) c++;
    return c;
}
int main() {
    int n;
    scanf("%d", &n);
    printf("%d\n", getOddFactorCount(n));
    return 0;
}
```

Verified: `10` → `2`; `25` → `3`
