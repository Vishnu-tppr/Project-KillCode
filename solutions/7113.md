# Id 7113 — Product of Two Halves Sum

```c
#include <stdio.h>

int main() {
    int a[100], n = 0;
    while (scanf("%d", &a[n]) == 1) n++;
    int half = n / 2;
    long long s1 = 0, s2 = 0;
    for (int i = 0; i < half; i++) s1 += a[i];
    for (int i = half; i < n; i++) s2 += a[i];
    printf("%lld\n", s1 * s2);
    return 0;
}

```

Verified: 9 1 2 8 7 2 -> 204\nExplanation:\nThe first half integers are 9, 1 and 2 and their sum is 12.\nThe second half integers are 8, 7 and 2 and their sum is 17.\nThe product of 12 and 17 is 204.\nHence the output is 204; 5 2 10 2 1 -> 91
