# Id 11872 — function getAlphabetsCount

```c
int getAlphabetsCount(char *S, int start, int end) {
    int c = 0;
    for (int i = start; i <= end; i++) {
        char x = S[i];
        if ((x >= 'a' && x <= 'z') || (x >= 'A' && x <= 'Z')) c++;
    }
    return c;
}
```
