# Id 6685 — Function printCharacterPattern - CTS PATTERN

```c
void printCharacterPattern(int num) {
    int i, j;
    for (i = 1; i <= num; i++) {
        for (j = 0; j < i; j++)
            printf("%c", 'a' + j);
        printf("\n");
    }
}
```
