# Id 6650 — Largest Floating Point Value

```c
#include <stdio.h>

int main() {
    double a, b, c;
    scanf("%lf%lf%lf", &a, &b, &c);
    double fa = a - (long)a, fb = b - (long)b, fc = c - (long)c;
    double m = a;
    double fm = fa;
    if (fb > fm) { fm = fb; m = b; }
    if (fc > fm) { fm = fc; m = c; }
    printf("%.2f\n", m);
    return 0;
}
```

Verified: `12.45 7.89 30.56 → 7.89`; `2.05 3.56 2.67 → 2.67` (the program prints the number whose fractional part is the largest)
