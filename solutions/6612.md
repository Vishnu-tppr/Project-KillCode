# Id 6612 — Square or Rectangle or Quadrilateral

```c
#include <stdio.h>

int main() {
    int a, b, c, d;
    scanf("%d%d%d%d", &a, &b, &c, &d);
    if (a == b && b == c && c == d)
        printf("SQUARE\n");
    else if (a == c && b == d)
        printf("RECTANGLE\n");
    else
        printf("QUADRILATERAL\n");
    return 0;
}
```

Verified: `4 4 4 4 → SQUARE`, `4 2 4 2 → RECTANGLE`, `4 5 6 7 → QUADRILATERAL`
