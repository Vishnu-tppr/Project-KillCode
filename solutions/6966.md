# Id 6966 — Cumulative Sum of Each Integer

```c
#include <stdio.h>
int main(){
    int a[4]; int i,sum=0;
    for(i=0;i<4;i++)scanf("%d",&a[i]);
    for(i=0;i<4;i++){
        sum+=a[i];
        if(i>0)printf(" ");
        printf("%d",sum);
    }
    printf("\n");
    return 0;
}
```

Verified: `2 4 6 7 → 2 6 12 19`; `7 3 17 23 → 7 10 27 50`
