# Id 6382 — C - Function - Digit Sum

```c
#include <stdio.h>
void printDigitSum(long long N) {
    int s = 0;
    while (N) { s += N % 10; N /= 10; }
    printf("%d", s);
}
int main() {
    long long n;
    scanf("%lld", &n);
    printDigitSum(n);
    printf("\n");
    return 0;
}
```
