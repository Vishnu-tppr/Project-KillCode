# Id 7082 — X Lines Integers Pattern

```c
#include <stdio.h>
int main(){
    int N,X;
    scanf("%d %d",&N,&X);
    for(int r=1;r<=X;r++){
        int cnt=1<<(r-1);
        long long v=(long long)r*N;
        for(int c=0;c<cnt;c++){
            if(c) printf(" ");
            printf("%lld",v++);
        }
        printf("\n");
    }
    return 0;
}
```

Verified: 8 5 → rows of 1,2,4,8,16 numbers ; 9 4 → rows of 1,2,4,8 numbers
