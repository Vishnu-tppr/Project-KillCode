# Id 6949 — Sum of Array Elements

```c
#include <stdio.h>
int main(){
    int n; int a[100]; int i;
    scanf("%d",&n);
    for(i=0;i<n;i++)scanf("%d",&a[i]);
    for(i=0;i<n/2;i++){if(i>0)printf(" ");printf("%d",a[i]+a[n-1-i]);}
    if(n%2==1){if(n/2>0)printf(" ");printf("%d",a[n/2]);}
    printf("\n");
    return 0;
}
```

Verified: `5\n12 3 4 5 8 → 20 8 4`; `8\n9 8 2 1 10 2 3 7 → 16 11 4 11`
