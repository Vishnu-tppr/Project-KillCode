# Id 6964 — Formatted Arithmetic Operations

```c
#include <stdio.h>
int main(){
    int x,y;
    scanf("%d %d",&x,&y);
    printf("%d+%d=%d\n",x,y,x+y);
    printf("%d-%d=%d\n",x,y,x-y);
    printf("%d*%d=%d\n",x,y,x*y);
    printf("%d/%d=%.2f\n",x,y,(double)x/y);
    return 0;
}
```

Verified: `4 5 → 4+5=9 / 4-5=-1 / 4*5=20 / 4/5=0.80`; `-3 14 → -3+14=11 / -3-14=-17 / -3*14=-42 / -3/14=-0.21`
